Hurricane Sandy Analysis: GFS Data

This script downloads, processes, and plots GFS (Global Forecast System) data for the 500mb Geopotential Height and Relative Humidity during Hurricane Sandy.

1. Prerequisites

Before running the code, ensure you have the required Python libraries installed. You can install them via pip:

pip install matplotlib numpy xarray cartopy

2. What the Code Does

  • Fetches Data: Accesses historical GFS weather models.
  • Processes Variables: Isolates the 500mb pressure level for geopotential height.
  • Visualizes: Plots the data onto a geographical map using Cartopy.
